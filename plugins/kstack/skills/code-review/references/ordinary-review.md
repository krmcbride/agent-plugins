# Ordinary Review

## Dispatch and resolve

Build the entry point's packet, including the selected depth and its investigation and stopping contract. Launch a fresh reviewer with that complete packet and preserve its handle. Keep the supplied inputs stable and wait for the complete review using the dispatch rules.

Use evidence to accept or challenge findings. Before acting on a blocking finding marked reproduced, rerun its exact command, in a disposable copy outside the reviewed checkout when it writes files, and treat the finding as reproduced only when the output shows the failure. Address authorized fixes after completion or a coordinated pause, and continue the same reviewer for clarification or verification of named repairs. Supply the updated artifact version and validation when files change. Start a fresh reviewer only when an independent second look is requested.

If the review exposes consequential uncertainty for which a critic would add value, return to the entry point's selection step. An ordinary review can serve as the initial adversarial review only if its complete output and stable IDs cover the same frozen artifact, requirements, selected depth, and material evidence questions. Otherwise continue the reviewer with the missing scope or evidence questions before introducing a critic; do not run overlapping reviews of changing inputs.

Return the outcome, material findings, validation, and coverage gaps. Reconcile interim findings and distinguish completed independent review from a local or partial assessment.
